===========================
How to use 1-my_list.py
===========================

Import the class:
    >>> MyList = __import__('1-my_list').MyList

Test basic sorted print:
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

Test original list is unchanged:
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Test empty list:
    >>> my_list2 = MyList()
    >>> my_list2.print_sorted()
    []

Test already sorted list:
    >>> my_list3 = MyList()
    >>> my_list3.append(1)
    >>> my_list3.append(2)
    >>> my_list3.append(3)
    >>> my_list3.print_sorted()
    [1, 2, 3]

Test list with negative numbers:
    >>> my_list4 = MyList()
    >>> my_list4.append(-3)
    >>> my_list4.append(0)
    >>> my_list4.append(-1)
    >>> my_list4.print_sorted()
    [-3, -1, 0]

Test single element:
    >>> my_list5 = MyList()
    >>> my_list5.append(42)
    >>> my_list5.print_sorted()
    [42]

Test MyList is subclass of list:
    >>> issubclass(MyList, list)
    True

Test instance is also a list:
    >>> my_list6 = MyList()
    >>> isinstance(my_list6, list)
    True
