===========================
How to use 3-say_my_name.py
===========================

Import the function:
    >>> say_my_name = __import__('3-say_my_name').say_my_name

Test basic full name:
    >>> say_my_name("John", "Smith")
    My name is John Smith

Test another full name:
    >>> say_my_name("Walter", "White")
    My name is Walter White

Test first name only (default last name):
    >>> say_my_name("Bob")
    My name is Bob 

Test first_name is not a string:
    >>> say_my_name(12, "White")
    Traceback (most recent call last):
    TypeError: first_name must be a string

Test last_name is not a string:
    >>> say_my_name("Bob", 42)
    Traceback (most recent call last):
    TypeError: last_name must be a string

Test both are not strings:
    >>> say_my_name(1, 2)
    Traceback (most recent call last):
    TypeError: first_name must be a string

Test first_name is None:
    >>> say_my_name(None, "White")
    Traceback (most recent call last):
    TypeError: first_name must be a string

Test last_name is None:
    >>> say_my_name("Bob", None)
    Traceback (most recent call last):
    TypeError: last_name must be a string

Test empty string first_name:
    >>> say_my_name("", "Smith")
    My name is  Smith

Test empty string last_name:
    >>> say_my_name("John", "")
    My name is John 

Test missing all arguments:
    >>> say_my_name()
    Traceback (most recent call last):
    TypeError: say_my_name() missing 1 required positional argument: 'first_name'
